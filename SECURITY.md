# Security Policy

## Supported versions

Security fixes are considered for the current default branch.

## Reporting a vulnerability

Please do not post security vulnerabilities in a public issue. Instead, contact the repository maintainer privately through the repository's contact method with:

- A clear description of the issue
- Steps to reproduce it
- The potential impact
- A suggested fix, if you have one

You should receive an acknowledgement within seven days. The maintainer will investigate, decide on a fix, and coordinate disclosure when appropriate.

## Local CBT server

The CBT result server is designed for local learning use. Do not expose it directly to the public internet or use it to store sensitive information.
